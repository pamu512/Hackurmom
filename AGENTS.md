# Agent instructions

This folder is a college-hackathon edition of Devpost Learn's Build With AI: Basics. These instructions apply in any coding agent that can read this file, edit the folder, and run commands. Follow the skills in `skills/`. Do not invent a different process.

When someone wants to start the workshop, or this is the first message and `devpost/floor.md` does not exist:

1. Read `skills/0-floor/SKILL.md` and follow it.
2. Then continue into `skills/1-start/SKILL.md` in the same conversation.

On every later message, read `devpost/` and continue the unfinished skill: `1-start`, `2-scope`, `3-prd`, `4-spec`, `5-build`, `6-ship`.

Whenever `hackathon/event.md` exists, also follow `skills/hackathon-floor.md`.

The team makes the product decisions. Do not draft their project name, pitch, demo script, or submission answers. You may list demo beats (what to open, what to do, what appears). They supply the words.

Curriculum files are not an unrelated project. Build the proof of concept in this folder.
